# 已知限制与后续事项

本文记录当前版本中已确认、但尚未处理的设置界面与 Provider 相关事项。它们不阻止现有图像生成主流程使用，但可能影响用户对配置含义的理解。

## 1. 提示词增强模型尚未接入生成流程

设置页目前可以把一个 Provider 的文本模型关联为“提示词增强模型”，并保存这项关联。但当前生成流程尚未实际调用该文本模型，也不会自动改写用户提示词。

当前行为：

- 关联配置可以保存和校验；
- 密钥、网关地址和模型配置复用被关联 Provider；
- 选择不会改变当前图像生成请求；
- 留空不会影响正常图像生成。

后续接入时需要明确增强发生的时机、增强失败时是否回退原提示词，以及增强调用是否计入生成确认中的调用量和费用估算。

## 2. 默认尺寸目前只是建议元数据

Provider 卡片中的“默认尺寸 WxH（建议值，供生成参考）”会保存并展示用户填写的尺寸，但当前生成请求仍使用任务中明确传入的宽高。该字段不会自动改变生成结果尺寸，也不是 Provider 调用的强制参数。

后续需要二选一：

- 将其接入生成表单，作为对应 Provider 的实际初始尺寸；或
- 如果产品不需要 Provider 级尺寸建议，则移除该字段，避免产生误解。

## 3. 费用币种目前按 Provider ID 推断

费用估算的币种当前只有 ID 为 `openai` 的 Provider 使用 `USD`，其他 Provider 默认使用 `CNY`。因此，自定义的海外网关、OpenAI 兼容服务或其他美元计费服务可能显示错误币种。

后续应增加可配置的 Provider 币种字段，并让预算确认和本地统计统一使用该字段。

## 4. 视频模型目录仍是预留配置

设置页支持保存视频模型目录，但视频能力尚未接入执行管线。视频模型只作为预留元数据保存，生成入口会阻止实际调用并说明原因。

如果视频功能短期内不会接入，可以考虑将该目录移到高级配置区域，降低设置页的信息密度；接入视频管线后再恢复为常规配置。

## 5. 当前版本的建议用法

- 暂时不要依赖“提示词增强模型”来改变生成结果；
- “默认尺寸”只当作备注，实际尺寸以生成任务设置为准；
- 自定义 Provider 的费用估算填写时，同时注意当前界面默认按人民币统计；
- 视频模型目录可以留空，填写也不会启用视频调用。

## 6. 基础角色来源锁定是不可逆设计（有意保留）

身份包的基础角色来源（AI 生成 / 本地导入）一旦确认锁定就**不可切换**，这是身份包
契约的有意设计：避免基准角色在两条路径之间反复横跳导致历史与版本语义混乱。锁定
发生在**确认执行**时（准备确认阶段无副作用），取消生成不会触发锁定。

由此派生的已知体验限制：

- 选择“本地导入”并锁定后，如果取消了文件选择，会停留在“已锁定导入但尚无候选”
  的状态——再次点击导入并选择文件即可继续，功能不受影响；
- 已弃用（rejected）的候选不可重新采用，防止身份基准回退。

如未来需要支持“重置来源”，必须连同身份包版本迁移一并设计，而不是简单放开校验。
