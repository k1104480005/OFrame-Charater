# OFrame Character 用户指南

> 面向独立游戏与像素游戏开发者的 2D 角色动画资产工作台。本文档描述在图形界面
> （Wails GUI）中完成一个完整角色的主流程，以及必须理解的关键业务概念：
> **方向集与镜像语义**、**生成确认与成本**、**质量验收**、**导出**。

## 0. 一个完整流程的速览

1. **启动页**：按分类浏览身份包卡片（全部 / 未分类 / 自定义，可拖拽卡片改分类、右键删分类），
   点「＋ 创建」弹窗创建新身份包，或点卡片「打开」进入工作台。
2. **制作 > 身份**：填写文字描述，可选添加参考图（1 主 + 最多 2 辅助）或既有精灵。
3. **制作 > 动作**：设置逻辑画布尺寸，新建动作并选择方向策略（单方向 / 4 / 8）。
4. **制作 > 动作**：点击「生成确认预览」查看预计调用量与预算，确认后执行
   （filmstrip 一次生成 + 确定性切片校正）。
5. **验收**：PixelPerfect 预览回放，查看质量评分，确认通过或拒绝候选；
   通过后成为当前动画资产；可对镜像方向做手动替换。
6. **导出**：检视已接受资产，选择引擎目标（通用序列帧 / Godot / Unity），
   生成并校验导出包，查看导出历史。

## 1. 方向集与镜像语义

- **默认单方向**：新动作默认只生成一个方向（`down`，正面/south），成本最低。
- **4 方向**：生成 `right / up / down`，`left` 由 `right` **水平翻转镜像派生**。
- **8 方向**：生成 `right / up / down / up-right / down-left`，其余 3 个方向镜像派生：
  `left ← right`、`up-left ← up-right`、`down-right ← down-left`；`up`/`down` 自对称。
- **镜像规则**：镜像方向拥有**独立的帧序列**（不是引用），锚点按
  `X' = 画布宽度-1-X, Y' = Y` 换算。
- **镜像的局限**：持械、非对称服装等细节在镜像后会反手/反边。可在「验收」标签对
  该方向执行**手动替换**（以额外调用重新生成该方向，替换结果计入生成确认的预计
  调用量）。
- **关闭镜像**：勾选取消「自动镜像」后，所有方向独立生成，不再派生镜像方向
  （成本随方向数线性增加）。

## 2. 生成确认与成本

- **生成确认**：任何可能产生外部 provider 调用的操作（新建动作生成、验收未通过后
  重新生成、验收时方向替换），都**先展示**：

  - 预计调用量（每个真实生成方向一次 filmstrip 调用；镜像方向**不消耗调用**）
  - 每方向最多尝试次数（默认 3 次总尝试）
  - 预算上限（总调用 × 每方向最多尝试）
  - 预计费用与费用上限（按 provider 单价估算）
  - 外发素材清单（哪些参考图会被发送给 provider）

  确认后才发起调用；**取消则零调用**。
- **失败自动重试**：单次调用失败自动退避重试（指数退避），达到每方向最多尝试
  次数后该方向失败，任务标记失败并记录原因，不再继续重试。
- **幂等去重**：与已成功任务完全相同的生成请求会**直接复用缓存结果，不重复计费**
  （任务抽屉中会标注「reused cached success result」）。
- **调用统计**：设置面板展示每个 provider/model 的调用次数与费用估算（本地保存）。

## 3. 质量验收

- 每个生成方向产出**生成候选**（含量化质量评分：切片完整性、锚点偏差、帧间抖动、
  色数/调色板一致性、越界像素等）。
- 验收关口：**评分达到阈值（默认 0.7）且 你在 PixelPerfect 预览中确认**，方可通过；
  通过后候选成为当前动画资产。未通过的候选保留在**候选历史**，不会消失。
- 拒绝或未接受的候选只属于候选历史；重新生成（新 filmstrip）遵循生成确认规则。
- 一致性粗评分（本地启发式或可选 AI）仅作参考展示，不阻塞验收流程。

## 4. 轻量编辑

编辑页提供对**已接受动画资产**的轻量校正：帧级（一键去背景/像素替换核心）、
序列级（删除帧、帧顺序调整、帧时长/节奏）、锚点级（偏移，应用到单帧或整方向集）、
批量（统一去背景到方向集全部帧）。所有编辑以**可回放的编辑指令**追加记录到操作日志
（非破坏式），支持从操作日志回退到任一历史点；编辑后的资产可重新导出。
帧级像素笔刷/橡皮/裁切的画布交互为后续增强（核心能力已实现）。

## 5. 导出

- 仅**验收通过**的动画资产可被检视与导出。
- 引擎目标：通用序列帧（generic）/ Godot / Unity。导出包包含：
  `spritesheet.png`（横向图集）+ `manifest.json` + 逐帧 PNG + 目标元数据
  （`generic.json` / `godot.json` / `unity.json`）。
- 每次导出**生成后自动校验完整性**（帧、锚点、清单），校验失败则导出失败并说明原因；
- 导出历史（目标、身份版本、时间、结果）记录在身份包的 `exports/history.jsonl`。

## 6. 设置

- **Provider 选择**：Doubao（默认）/ gpt-image-2 / Agnes，运行时切换。
- **密钥/模型配置**：本地明文存储（仅本机可读），离线校验；密钥永不回传、不进导出包。
- **每方向最多尝试次数**：生成确认的预算控制。
- **外观主题**：暖白 / 深墨双主题，即时生效并本地持久化。
- **任务抽屉**：跨标签可见，展示进行中 / 排队 / 失败任务；失败可查看原因并重试或放弃。

## 7. 常见问题

- **生成失败且任务标记失败？** 打开任务抽屉查看原因；可在确认预算内重试，或放弃。
- **镜像方向不自然？** 在验收标签对该方向执行手动替换（额外调用，计入生成确认）。
- **密钥保存在哪里？** `%AppData%\OFrameCharacter\settings.json`，仅本机。
- **如何把项目给其他人？** 身份包是普通目录 + manifest，可复制、可归档；
  对方把目录放进自己的工作区，启动页「全部」分类下即可看到并打开。
