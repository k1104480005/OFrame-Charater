# 人工测试清单（Manual Test Checklist）

> 用途：发布前人工验收，覆盖示例资产、Provider 设置、真实密钥生成和边界恢复。
> 分为：A. 无密钥的示例资产全流程；B. 真实密钥的生成流程；C. 边界与恢复。
> 每项记录：操作 → 期望 → 实际 → 问题描述（便于反馈给开发者）。

## 0. 启动应用

- [ ] 双击 `build/bin/OFrameCharacterWorkbench.exe`（便携版）可启动；
      若提示 SmartScreen：更多信息 → 仍要运行。
- [ ] 启动页为 v2 布局：右上角「＋ 创建」「工作区」按钮、左侧分类栏
      （全部 / 未分类 / 新建分类）、右侧身份包卡片网格（缩略图 + 名称 + 版本 + 创建/修改时间）。

## A. 示例资产全流程（无需密钥）

> 示例身份包：`D:\OFrameCharater\examples\hero-walk`（32×32，4 方向行走，3 个已接受候选）。

### A0. 启动页功能（v2）
- [ ] 「全部」分类下列出所有身份包；点「未分类」/自定义分类可过滤。
- [ ] 左栏底部输入名称 + 回车/＋ 可新建分类（空分类计数 0）。
- [ ] **拖拽**一张卡片到某个分类 → 该包分类立即改变并刷新列表。
- [ ] **右键**分类 → 菜单「删除分类」→ 确认后该分类下所有包自动归「未分类」。
- [ ] 点卡片上的**名字**可改名（回车/点别处保存，Esc 取消）。
- [ ] 点卡片右上角红 ✕ → 动森确认弹窗 → 包被移到工作区 `.trash`（可从文件管理器找回）。
- [ ] 「＋ 创建」弹窗：输入名称 + 选择分类 → 创建并进入工作台；「工作区」弹窗可浏览/切换目录。

### A1. 打开示例
- [ ] 启动页「全部」分类下找到 Hero 卡片 → 点「打开」进入三标签工作台。
- [ ] 顶部显示包名 Hero 与 format v1。

### A2. 制作 > 身份
- [ ] 文字描述可见（绿色像素小英雄…）；逻辑画布 32×32；脚底锚点存在。
- [ ] 修改描述 → 保存 → 切换标签再回来不丢失。

### A3. 制作 > 动作
- [ ] 动作列表含 walk；方向集 4 个方向：right/up/down 为「生成」，left 为「镜像派生」。
- [ ] 点「节奏」能加载该方向帧时长；修改后保存生效。

### A4. 制作 > 编辑（轻量编辑）
- [ ] 选择 walk / right → 帧条显示 4 个缩略图。
- [ ] 选中帧 0 → 点「删除选中帧」→ 帧数变 3，操作日志新增 edit 条目。
- [ ] 选中帧 → 「上移/下移」→ 顺序变化且缩略图随之变化。
- [ ] 修改「帧时长(ms)」→ 应用时长 → 预览节奏变化。
- [ ] 「批量去背景」→ 无报错，帧数不变。
- [ ] 锚点偏移（ΔX/ΔY 非 0）→ 应用到整方向集无报错。
- [ ] （回归）「验收」标签能看到本次编辑在操作日志中记录。

### A5. 验收
- [ ] 选择 walk/right → PixelPerfect 预览播放/暂停、网格/锚点/洋红开关均生效。
- [ ] 候选历史：3 条已接受（综合 0.95）。
- [ ] 操作日志：生成/接受/编辑条目可见；「回退至此」可回退（回退后资产恢复该点状态）。

### A6. 导出
- [ ] 资产检视：已接受资产清单 + 帧序列 + 锚点清单显示。
- [ ] 选择目标（generic/godot/unity）+ 输出目录 → 「生成并校验导出包」→ 成功提示。
- [ ] 输出目录含 spritesheet.png + manifest.json + 逐帧 PNG + 目标 json。
- [ ] 「校验现有导出包」通过；导出历史新增一条成功记录。

### A7. 设置与全局
- [ ] 齿轮 → Provider 列表为空（全新安装不预置），统计可见。
- [ ] 从八个预设快速添加 → 卡片出现；删除按钮对所有卡片可用（含内置身份），删除后可重新添加。
- [ ] 外观主题：暖白/深墨切换即时生效并持久化（重启后仍保持）。
- [ ] TASKS 抽屉：跨标签可见，无任务时为空态。

### A8. Provider 预设与模型分类（align-framebaker-providers）
- [ ] 设置 → 快速添加出现八个预设：OpenAI、百炼、banana/Gemini、MiniMax、
      火山方舟/豆包、自定义 CLI、自定义 API、Agnes（免费多模态）；每项带
      协议标签与字段说明（悬停可见），预设按钮文字为主题色（无纯白文字）。
- [ ] 逐个添加预设 → 每张卡片显示协议徽标；重复添加同一预设 → 按钮显示「已配置 n」。
- [ ] 卡片字段按协议切换：CLI 卡无 Base URL/密钥，出现命令/参数字段；
      HTTP 卡出现 Base URL、默认尺寸和图像/视频/文本三个独立模型目录输入。
- [ ] Agnes 卡为多模态（图像 + 文本徽标）；填入 API Key → 测试连接（真实网关
      apihub.agnes-ai.com/v1）→ 获取模型；旧版占位地址的卡片重启后自动迁移为新端点。
- [ ] 修改卡片字段后直接点「测试连接」→ 内联显示延迟/模型数/错误；不点保存 → 重开设置确认配置未被修改
      （草稿测试零持久化）。
- [ ] 「获取模型」→ 模型 chips 列表；切换能力目标（图像/视频/文本）+ 输入过滤词
      → 点选 chip 加入/移出目标目录；手输模型保留。
- [ ] 提示词增强关联：选择文本能力 Provider + 文本模型 → 保存；删除该 Provider →
      重启后关联自动回退为「跟随当前 Provider」。当前版本仅验证关联保存/校验，提示词增强
      尚未接入实际生成流程，不应以生成结果变化作为验收条件。
- [ ] 生成入口（动作页）：Provider 下拉只列出图像能力可选项，不可用项显示原因并禁用；
      显式选择 Provider/模型后确认面板展示协议、Provider、模型、能力、调用量与重试上限。
- [ ] 自定义 CLI 失败恢复：命令不存在/退出码非零/输出缺失/格式错误 → 生成结果分别给出
      可读原因；引用图未配置引用图参数 → 启动前拒绝。
- [ ] 无密钥边界：未配置密钥时「测试连接」给出可读错误且不发起计费调用；
      密钥仅显示状态徽标，不回显原文。
- [ ] 视频预留：某 Provider 保存视频模型 → 重启后目录恢复；生成入口不出现视频选项，
      视频调用被明确阻止（预留说明，而非静默失败）。

## B. 真实密钥生成流程（可选，需付费 API）

- [ ] 设置 → 配置一个可用的 HTTP Provider API Key → 离线校验通过。
- [ ] 制作 > 动作 → 新建动作（如 idle，单方向）→ 生成确认预览显示协议/Provider/模型/能力、
      预计调用量/预算。
- [ ] 取消 → 确认未发起任何调用（provider stats 不变）。
- [ ] 确认执行 → 任务抽屉出现任务 → 完成 → 候选出现在验收标签。
- [ ] 验收 → 评分 + 预览确认 → 成为资产 → 导出。
- [ ] （可选）八个预设逐一用真实密钥或本地命令验证：OpenAI / 百炼 / banana/Gemini /
      MiniMax / 火山方舟/豆包 / 自定义 API / Agnes 测试连接、获取模型与生成各走通一次；
      自定义 CLI 按命令执行和失败恢复清单验证（按协议发出，无静默替换）。

## C. 边界与恢复

- [ ] 生成失败（密钥错误/断网）→ 任务标记失败并显示原因；可重试/放弃。
- [ ] 相同请求重复执行 → 幂等缓存复用，不重复计费（任务备注含 reused cached）。
- [ ] 应用运行中强杀 → 重启后「一键续跑」恢复未完成任务。
- [ ] 设置里 maxAttempts 改为 1 → 失败后重试被拒绝（遵守确认上限）。
- [ ] 关闭再打开应用 → 上次打开的身份包自动恢复（持久化会话）。
