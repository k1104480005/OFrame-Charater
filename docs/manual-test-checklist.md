# 人工测试清单（Manual Test Checklist）

> 用途：发布前人工验收（对应 13.4「外部用户可完成一个完整角色资产」）。
> 分为：A. 无密钥的示例资产全流程；B. 真实密钥的生成流程；C. 边界与恢复。
> 每项记录：操作 → 期望 → 实际 → 问题描述（便于反馈给开发者）。

## 0. 启动应用

- [ ] 双击 `build/bin/OFrameCharacterWorkbench.exe`（便携版）可启动；
      若提示 SmartScreen：更多信息 → 仍要运行。
- [ ] 启动页为 v2 布局：右上角「＋ 创建」「工作区」按钮、左侧分类栏
      （全部 / 未分类 / 新建分类）、右侧身份包卡片网格（缩略图 + 名称 + 版本 + 创建/修改时间）。

## A. 示例资产全流程（无需密钥）

> 示例身份包：`D:\OFrameCharater\examples\hero-walk`（32×32，4 方向行走，3 个已接受候选）。

### A0. 启动页功能（v2）
- [ ] 「全部」分类下列出所有身份包；点「未分类」/自定义分类可过滤。
- [ ] 左栏底部输入名称 + 回车/＋ 可新建分类（空分类计数 0）。
- [ ] **拖拽**一张卡片到某个分类 → 该包分类立即改变并刷新列表。
- [ ] **右键**分类 → 菜单「删除分类」→ 确认后该分类下所有包自动归「未分类」。
- [ ] 点卡片上的**名字**可改名（回车/点别处保存，Esc 取消）。
- [ ] 点卡片右上角红 ✕ → 动森确认弹窗 → 包被移到工作区 `.trash`（可从文件管理器找回）。
- [ ] 「＋ 创建」弹窗：输入名称 + 选择分类 → 创建并进入工作台；「工作区」弹窗可浏览/切换目录。

### A1. 打开示例
- [ ] 启动页「全部」分类下找到 Hero 卡片 → 点「打开」进入三标签工作台。
- [ ] 顶部显示包名 Hero 与 format v1。

### A2. 制作 > 身份
- [ ] 文字描述可见（绿色像素小英雄…）；逻辑画布 32×32；脚底锚点存在。
- [ ] 修改描述 → 保存 → 切换标签再回来不丢失。

### A3. 制作 > 动作
- [ ] 动作列表含 walk；方向集 4 个方向：right/up/down 为「生成」，left 为「镜像派生」。
- [ ] 点「节奏」能加载该方向帧时长；修改后保存生效。

### A4. 制作 > 编辑（轻量编辑）
- [ ] 选择 walk / right → 帧条显示 4 个缩略图。
- [ ] 选中帧 0 → 点「删除选中帧」→ 帧数变 3，操作日志新增 edit 条目。
- [ ] 选中帧 → 「上移/下移」→ 顺序变化且缩略图随之变化。
- [ ] 修改「帧时长(ms)」→ 应用时长 → 预览节奏变化。
- [ ] 「批量去背景」→ 无报错，帧数不变。
- [ ] 锚点偏移（ΔX/ΔY 非 0）→ 应用到整方向集无报错。
- [ ] （回归）「验收」标签能看到本次编辑在操作日志中记录。

### A5. 验收
- [ ] 选择 walk/right → PixelPerfect 预览播放/暂停、网格/锚点/洋红开关均生效。
- [ ] 候选历史：3 条已接受（综合 0.95）。
- [ ] 操作日志：生成/接受/编辑条目可见；「回退至此」可回退（回退后资产恢复该点状态）。

### A6. 导出
- [ ] 资产检视：已接受资产清单 + 帧序列 + 锚点清单显示。
- [ ] 选择目标（generic/godot/unity）+ 输出目录 → 「生成并校验导出包」→ 成功提示。
- [ ] 输出目录含 spritesheet.png + manifest.json + 逐帧 PNG + 目标 json。
- [ ] 「校验现有导出包」通过；导出历史新增一条成功记录。

### A7. 设置与全局
- [ ] 齿轮 → provider 列表（doubao/openai/agnes）与统计可见。
- [ ] 外观主题：暖白/深墨切换即时生效并持久化（重启后仍保持）。
- [ ] TASKS 抽屉：跨标签可见，无任务时为空态。

## B. 真实密钥生成流程（可选，需付费 API）

- [ ] 设置 → 配置 Doubao API Key → 离线校验通过。
- [ ] 制作 > 动作 → 新建动作（如 idle，单方向）→ 生成确认预览显示预计调用量/预算。
- [ ] 取消 → 确认未发起任何调用（provider stats 不变）。
- [ ] 确认执行 → 任务抽屉出现任务 → 完成 → 候选出现在验收标签。
- [ ] 验收 → 评分 + 预览确认 → 成为资产 → 导出。

## C. 边界与恢复

- [ ] 生成失败（密钥错误/断网）→ 任务标记失败并显示原因；可重试/放弃。
- [ ] 相同请求重复执行 → 幂等缓存复用，不重复计费（任务备注含 reused cached）。
- [ ] 应用运行中强杀 → 重启后「一键续跑」恢复未完成任务。
- [ ] 设置里 maxAttempts 改为 1 → 失败后重试被拒绝（遵守确认上限）。
- [ ] 关闭再打开应用 → 上次打开的身份包自动恢复（持久化会话）。
