## Context

当前工作台的 Go 核心已经以身份包为边界，提供动作策略、生成确认、任务、候选验收、编辑日志和导出。perfectpixel-studio 已验证基础角色生成、动作列表、右侧预览、帧控制和反馈重生成。融合必须优先复用现有核心服务，不复制一套平行会话或生成管线。

## Goals

- 让基础角色生成成为身份流程的首个可选入口。
- 让当前身份、动作、方向、候选和预览成为共享会话上下文。
- 让用户从选择对象到预览、生成、验收、编辑和导出保持连续。
- 保留外部调用确认、能力筛选、预算、任务恢复、候选历史和版本回退。

## Non-goals

- 本变更不实现完整像素绘图软件。
- 不删除 FrameBaker 的身份包、版本或 CLI 能力。
- 不替换已有确定性图像处理管线。
- 不新增视频生成执行能力。

## Architecture

```text
IdentityPackage
  ├─ base character / references / canvas / anchors
  └─ accepted motion assets
          │
          ▼
  WorkbenchSessionContext
  ├─ current identity
  ├─ current motion + direction
  ├─ current candidate / accepted asset
  └─ preview controls
          │
          ├─ GenerationPlan → TaskQueue → Pipeline
          ├─ CandidateHistory → Acceptance / VersionLog
          ├─ EditInstructions → AcceptedAsset
          └─ AcceptedAsset → Export + Validate
```

基础角色生成沿用 perfectpixel 的输入语义，但必须通过 FrameBaker 的共享服务、Provider registry、能力校验、确认计划和任务队列。候选结果先进入会话和候选历史，只有采用/接受后才写入身份基准或当前资产。

## UI Composition

采用阶段化的预览优先工作区，而不是重复的摘要侧栏：顶层导航平铺为“身份 / 动作 / 验收 / 导出”，每个标签对应一个明确的用户目标。取消“制作”包装和独立“编辑”标签；编辑是验收阶段对当前已接受资产的上下文操作。

工作区使用统一骨架，但侧栏内容随阶段变化：身份阶段展示素材、基础角色候选、画布和锚点；动作阶段展示动作/方向列表、生成计划和任务状态；验收阶段展示候选/方向列表，中央显示当前 PixelCanvas，操作区承载播放、逐帧、评分、接受、替换、编辑和回滚；导出阶段展示已接受资产与导出预览。顶部只保留身份包名称/版本、任务、设置和返回等全局信息，不再重复显示“当前身份 / 当前对象”摘要。

身份页采用单列布局并按来源分型：来源未锁定时只显示来源选择；锁定后渲染单一合并工作流面板 —— AI 来源为「①角色描述 → ②参考图 → ③逻辑画布 → ④生成任务/确认门 → ⑤候选与采用」，本地导入来源为「①角色描述（档案）→ ②逻辑画布 → ③导入角色图 → ④候选与采用」；另一来源的控件不渲染（而非禁用）。基础角色来源是身份包级不可变属性，用户必须明确确认“AI 生成”或“导入已有角色图”之一；锁定后另一条路径在 UI 与服务层均不可用。锚点（含当前基准图与锚点叠加预览）作为共用收尾面板；身份包 ID、当前版本与版本历史以可展开列表并入页首状态区，不设独立版本面板。操作反馈以页面顶部状态条呈现，不沉底。

四个阶段共用一个 `WorkbenchContext`；视图只负责展示和发出领域操作。切换视图不重置当前对象，草稿保存状态单独标识。现有 `TaskDrawer` 保持全局入口，生成完成事件更新当前候选并自动聚焦预览。

## Data Compatibility

已有身份包没有基础角色候选字段时，按“既有精灵/参考素材”模式继续工作。新增会话字段采用可选版本化字段；无法恢复的当前选择只清除选择，不删除资产。导出仍以已接受资产和当前身份版本为唯一输入。

## Error Handling

所有 Provider、模型、素材、画布和预算错误在确认前离线阻止。任务失败保留原候选和错误；取消不修改当前资产。视图加载失败不清除会话上下文，提供重试入口。

## Verification

使用 Go 单元测试覆盖基础角色计划、候选采用、兼容旧身份包、确认取消和任务恢复；前端执行构建与类型检查；通过真实 GUI 验收完整路径、无 Provider 边界、未保存草稿、切换对象、候选拒绝/重生成、编辑回退和导出校验。
