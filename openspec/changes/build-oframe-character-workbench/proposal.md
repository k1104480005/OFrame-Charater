# Proposal: build-oframe-character-workbench

## Why

独立游戏与像素游戏开发者缺少一条「从文字/参考图/既有精灵到可直接导入引擎的 2D 角色动画资产」的本地优先流水线：通用绘图工具没有确定性校正与方向一致性，引擎内置流程不覆盖生成→验收→导出的完整工作流。本项目（工作代号 OFrame Character）构建本地优先桌面工作台，以可版本化的「角色身份包」为根对象，用 PerfectPixel filmstrip 确定性管线保证帧间与方向间一致性，让一个角色从入口到 4 方向行走动画资产可在一个会话内完成并中断恢复。

## What Changes

- 构建 Go + Wails 桌面工作台（Windows 10/11 x64 首发），React + TypeScript 前端、PixiJS 预览画布；oframe CLI 与 GUI 共享同一 Go 核心库，作为可脚本化管线入口。
- 引入「角色身份包」根对象（本地目录 + manifest）：承载身份定义、逻辑画布规格、锚点定义、动作/方向集/帧序列、候选历史、身份版本与追加式操作日志。
- 引入可插拔生成 provider：统一 Provider 接口与适配器（Doubao 默认主力、gpt-image-2 高质量备选、Agnes 专项备选），本地密钥/额度/调用统计，失败自动重试且有上限。
- 引入「生成确认」：任何可能产生外部调用的操作先展示预计调用量与最大重试次数，经用户确认后执行，杜绝静默超支。
- 引入 PerfectPixel filmstrip 确定性管线：规格化 → 一次提示词生成整条胶片条（保证帧间一致性）→ 确定性整数像素级切片 → 确定性校正（锚点、透明背景、裁边留白）→ PixelPerfect 预览 → 质量验收。
- 引入方向策略：新动作默认单方向；4/8 方向时仅生成基本方向，其余方向水平翻转镜像派生（独立帧序列 + 锚点镜像换算），允许验收时按方向手动替换。
- 引入质量评分与质量验收关口：结构指标（切片完整性、锚点偏差、抖动）+ 规则指标（色数、镜像对称性、越界像素）+ 可选 AI 粗评分；评分达阈值且用户确认方通过。
- 引入可恢复任务队列：任务持久化到本地，跨应用开关保持连续，中断后可一键续跑；同任务成功结果缓存去重，避免重复计费。
- 引入轻量编辑：帧级（裁切、透明清理、像素替换）、序列级（帧顺序/时长）、锚点级（拖拽调整）、批量应用；编辑以可回放指令记录，非破坏式。
- 引入版本化修订：明确外观修订形成不可变身份版本；候选接受为业务动作；追加式操作日志支持回退到任一历史点。
- 引入导出包：面向 Godot / Unity / 通用序列帧的引擎目标格式，导出包生成与校验，导出历史。
- 构建三标签界面（制作 / 验收 / 导出）+ 启动页（仅身份包选择/创建）+ 全局设置 + 任务抽屉；暖白/深墨双主题像素化视觉（8px 间距栅格、像素边框、状态色专用、洋红仅用于抠图技术背景）。
- 明确不做（非目标）：3D/骨骼网格/物理仿真、通用图像编辑器、云端协作、生成模型训练、游戏引擎运行时；macOS/Linux、批量任务等列为 P3 扩展，不在首发承诺内。

## Capabilities

### New Capabilities

- `identity-package`: 角色身份包根对象 —— 目录 + manifest 结构、身份定义入口（文字描述/参考图/既有精灵）、逻辑画布规格、锚点定义与预设
- `motion`: 动作、方向集、帧序列的数据模型与操作；方向策略（单方向默认 / 4 方向 / 8 方向自动镜像）与镜像派生
- `generation`: 生成 provider 抽象与适配器（Doubao / gpt-image-2 / Agnes）、生成确认、密钥/额度/调用统计、限流与重试
- `filmstrip-pipeline`: PerfectPixel filmstrip 确定性管线 —— 规格化、胶片条生成、确定性整数像素切片、确定性校正、PixelPerfect 预览
- `quality`: 质量评分（结构/规则/可选 AI 指标）、质量验收关口、候选历史
- `tasks`: 可恢复任务队列 —— 持久化、跨会话续跑、幂等去重、失败原因与重试/放弃
- `editing`: 轻量编辑 —— 帧级/序列级/锚点级/批量能力，编辑指令可回放
- `versioning`: 版本化修订 —— 身份版本、候选接受、追加式操作日志与回退
- `export`: 导出包生成与校验（Godot / Unity / 通用序列帧）、导出历史
- `workbench-ui`: 桌面工作台界面 —— 启动页、三标签主界面、设置、任务抽屉、暖白/深墨双主题视觉系统
- `cli`: oframe CLI 可脚本化管线（批量生成、校验、导出），与 GUI 共享 Go 核心库

### Modified Capabilities

无 —— 本变更首次引入全部能力，不存在既有规格被修改。

## Impact

- **新代码库**：Go 核心库（`identity` / `motion` / `pipeline` / `provider` / `task` / `edit` / `version` / `export` 模块）、Wails 桌面壳、React + TypeScript 前端、PixiJS 画布、oframe CLI（Go 同源）。
- **依赖**：Wails v2（Windows 打包/系统集成）、React + TypeScript、PixiJS、各生成 provider HTTP API、NSIS（安装包，便携版并行）。
- **外部服务**：生成调用产生外部 API 费用 —— 依赖生成确认、调用量预估、去重缓存与本地调用统计控制成本。
- **交付物**：Windows 安装包与免安装便携版、公开 Beta；身份包格式带版本号与迁移器。
- **风险面**：provider 生成一致性、镜像方向不自然、生成成本失控、Wails 打包问题、PixiJS 多帧性能、身份包格式演进 —— 均已在设计阶段给出对策。
