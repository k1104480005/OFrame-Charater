## 3. 动作与方向集（motion spec）

- [x] 3.1 实现动作、方向集、帧序列的数据结构与操作，验证单元测试覆盖「动作由方向集构成、每方向一份独立帧序列」
- [x] 3.2 实现单方向默认策略，验证新建动作默认只含单一方向（down/正面/south）
- [x] 3.3 实现 4/8 方向自动镜像：仅基本方向发起生成调用、其余方向水平镜像派生，验证 4 方向为 3 生成 + 1 镜像（右/上/下生成，左镜像），8 方向为 5 生成 + 3 镜像（右/上/下/右上/左下生成，左/左上/右下镜像；down 自对称、右下单向派生自左下——复核报告语义）且映射正确；关闭镜像时所有方向独立生成
- [x] 3.4 实现镜像方向独立帧序列与锚点镜像换算，验证派生方向帧序列独立存在且锚点坐标按水平镜像规则换算（X' = width-1-X, Y' = Y）
- [x] 3.5 实现镜像方向手动替换（验收时以额外调用替换），验证替换计入生成确认的预计调用量且方向集更新
- [x] 3.6 实现帧时长（节奏）元数据，验证调整后预览按新节奏回放

## 4. Provider 与生成（generation spec）

- [x] 4.2 实现 Doubao 适配器（默认主力），验证首次生成默认路由到 Doubao

- [x] 4.5 实现生成确认流程：任何可能产生外部调用的操作先展示预计调用量与最大重试次数，验证确认后执行、取消则不发起任何调用
- [x] 4.6 实现本地密钥、额度与调用统计管理，验证配置密钥后调用可用、每次调用后统计（次数与费用估算）更新
- [x] 4.7 实现失败自动重试（退避）与硬上限，验证低于上限自动重试、达到上限任务失败且记录原因、不再继续重试
- [x] 4.8 实现幂等结果缓存，验证重新提交与已成功任务相同的任务直接复用缓存、不发起新调用

## 5. PerfectPixel 管线（filmstrip-pipeline spec）

- [x] 5.1 实现帧清单规格化（依据逻辑画布定长、定序），验证规格化输出帧数/尺寸/坐标符合规格
- [x] 5.2 实现 filmstrip 生成：同一动作所有帧按帧序横向拼成胶片条、一次提示词生成，验证一次调用产出包含全部帧的胶片条
- [x] 5.3 实现确定性切片（整数像素级，无二次插值模糊），验证切片帧数与尺寸精确、缩放/位移为整数像素；切片与规格不符时任务失败且不产出部分资产
- [x] 5.4 实现确定性校正：锚点校正到规格坐标、透明背景处理（洋红仅用于抠图技术背景）、裁边与留白按逻辑画布对齐，验证各校正项单元测试通过
- [x] 5.5 实现 PixelPerfect 预览：最近邻采样回放、网格叠加与锚点可视化可开关，验证预览渲染与切片结果逐像素一致
- [x] 5.6 实现验收未通过后的重新生成（新 filmstrip），验证重试遵循生成确认规则

## 7. 轻量编辑（editing spec）

- [x] 7.1 实现帧级编辑：裁切、透明背景清理（去边/去残留）、像素替换（橡皮/取色/单像素笔刷），验证编辑以指令记录且原帧数据不被破坏
- [x] 7.2 实现序列级编辑：帧顺序调整、插入/删除帧、帧时长调整，验证调整后序列按新顺序保存且时长保留
- [x] 7.3 实现锚点级编辑：拖拽调整锚点、应用于单帧或整方向集，验证整方向集应用后全部对应帧锚点按规则更新
- [x] 7.4 实现批量编辑：同一校正（如统一去背景）批量应用到方向集全部帧，验证全部帧应用同一指令
- [x] 7.5 实现可回放编辑指令：追加式指令序列可重放得到当前结果，编辑结果可重新进入质量评分，验证重放与重新评分链路

- [x] 8.3 实现质量验收关口：评分达阈值且用户在 PixelPerfect 预览确认方通过，验证通过/拒绝两分支行为正确
- [x] 8.4 实现候选历史：未接受候选连同评分与验收结果写入身份包元数据，验证拒绝或未接受的候选保留在候选历史中
